# Custom skies

**[English](README.md)** | **Русский**

Custom skies — плагин AMX Mod X для Counter-Strike 1.6 на ReHLDS, который ставит кастомный скайбокс на каждой карте: случайный из общего списка, фиксированный или случайный из списка конкретной карты, либо вообще никакой — тогда остаётся скайбокс, вшитый в карту. Рассчитан на владельцев серверов, которым нужны свои небеса без правки карт.

## Возможности

- Случайное небо из списка `[list random skies]` на каждой карте.
- Настройки по картам в `[map settings]`: одно небо или несколько, из которых при каждой загрузке карты случайно выбирается одно.
- `none` для карты: плагин ничего не меняет, используется скайбокс, вшитый в карту.
- Прекэшируются только шесть текстур выбранного неба, поэтому игрок скачивает одно небо, а не весь список.
- Небеса с недостающими файлами текстур пропускаются, а отсутствующий файл записывается в лог AMXX.

## Требования

- AMX Mod X 1.8.3 или новее (проверено на 1.10.0.5484)
- Дополнительные модули не нужны

## Установка

1. Скачайте `custom_skies.sma`.
2. Скомпилируйте плагин:
   - локально (рекомендуется): положите `.sma` в `scripting/` и запустите компилятор;
   - через веб-компилятор.
3. Скопируйте `custom_skies.amxx` в `addons/amxmodx/plugins/`.
4. Скопируйте `addons/amxmodx/configs/custom_skies.ini` в `addons/amxmodx/configs/`.
5. Скопируйте текстуры неба в `cstrike/gfx/env/`. В репозитории лежат два неба, `nebulous` и `plume`, в `gfx/env/`.
6. Добавьте `custom_skies.amxx` в `addons/amxmodx/configs/plugins.ini`.
7. Смените карту или перезапустите сервер.

### Обновление с 0.1.0

- Плагин и конфиг переименованы: `CustomSkies.amxx` → `custom_skies.amxx`, `CustomSkies.ini` → `custom_skies.ini`. Замените строку в `plugins.ini` и удалите старые файлы.
- Формат конфига изменился. Прежний простой список названий переносится под `[list random skies]`.
- Символа комментария `#` больше нет, используйте `;`.

## Настройка

Плагин читает `addons/amxmodx/configs/custom_skies.ini` при старте карты. Небо задаётся префиксом текстур без суффикса стороны: имя `nebulous` означает файлы `gfx/env/nebulousbk.tga`, `nebulousdn.tga`, `nebulousft.tga`, `nebulouslf.tga`, `nebulousrt.tga` и `nebulousup.tga`. В имени может быть подпапка, например `skyservers/milky`.

| Секция | Содержимое |
|--------|------------|
| `[list random skies]` | По одному названию неба в строке. Используется на каждой карте, у которой нет рабочей строки в `[map settings]`. |
| `[map settings]` | Строки вида `карта = небо` или `карта = небо1, небо2, ...`. |

| Значение `карта = ...` | Результат |
|-------------------------|-----------|
| `небо` | На карте всегда ставится это небо. |
| `небо1, небо2, ...` | При каждой загрузке карты случайно выбирается одно из перечисленных. |
| `none` | Небо не ставится, используется скайбокс, вшитый в карту. |
| `none, небо1, ...` | `none` — один из вариантов случайного выбора. |

Пример:

```ini
[list random skies]
nebulous
plume

[map settings]
de_dust2 = none
de_inferno = nebulous
de_nuke = nebulous, plume
```

Правила:

- `;` начинает комментарий, в том числе в конце строки. Символ `#` комментарием не является.
- Названия карт сравниваются без учёта регистра.
- Если карта указана несколько раз, действует последняя строка.
- Если ни одно небо в строке карты не годится (нет файлов текстур), плагин берёт `[list random skies]`.
- Если не осталось ни одного рабочего неба, остаётся скайбокс карты, и лог AMXX это отмечает.
- Секции с другими именами и секции без закрывающей скобки игнорируются и пишутся в лог.

## Технические заметки

- Небо выбирается, а `sv_skyname` ставится в `plugin_precache`. Плагин регистрирует квар `CustomSkies_version`, только для чтения.
- Шесть текстур выбранного неба добавляются в список ресурсов через `precache_generic`, поэтому клиенты скачивают их с сервера.
- Текстура с заглавным суффиксом стороны (`nebulousBK.tga`) переименовывается на сервере в нижний регистр, потому что поиск файлов в Linux чувствителен к регистру.
- Конфиг читается один раз за карту. Изменения применяются со следующей загрузки карты.
- Названия карт сопоставляются точно: масок и префиксов нет.
- Если `custom_skies.ini` не открывается, плагин останавливается с ошибкой `Unable to open file`.
